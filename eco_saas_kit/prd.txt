5.1 Enhanced SaaS Plan Management
Description:
Extend Webkul plan model to support modern SaaS packaging.
Functional Requirements:
•	Create/Edit/Delete plans
•	Plan attributes:
o	Name
o	Domain type (HR, Education, Corporate)
o	Pricing model
o	Billing cycle
o	Token allocation
o	User limits
•	Multi-tier support:
o	Basic / Professional / Enterprise
Acceptance Criteria:
•	Admin can configure plans with tokens and features
•	Plans can be assigned to subscriptions

o	Fixed
o	Per user
o	Usage-based (token)
o	Hybrid
Functional Requirements:
•	Dynamic pricing calculation
•	Currency conversion support
Acceptance Criteria:
•	System calculates final payable amount correctly
________________________________________
5.3 Discount Engine
Description:
Enable marketing-driven pricing flexibility.
Functional Requirements:
•	Create discount:
o	Type: % / fixed
o	Scope: Plan / user / global
o	Validity period
o	Usage limit
•	Coupon system:
o	Unique codes
•	Auto-apply rules

•	Discount applied correctly
•	Expired coupons rejected
